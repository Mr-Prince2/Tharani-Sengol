1. Permit Verification Module (IMPORTANT)

The problem statement says:

“transporting earth excavated under permitted conditions”

Currently your system tracks vehicles,
but does not fully validate permits.

Add:
Permit Database

Store:

Permit ID
Allowed excavation quantity
Approved route
Allowed trip count
Valid dates
Vehicle number
Then Verify:

When GPS trip starts:

Check permit validity
Check allowed route
Check remaining quantity
Check max trips allowed

If violated:
→ Generate alert

This is VERY important.

4. Excavation Quantity Tracking

Currently you predict truck weight.

Enhance it:

Total Excavated Quantity =
Sum of all predicted loads

Then compare with:

Permitted Excavation Quantity

If exceeded:
→ illegal mining alert

This perfectly solves the core problem.
